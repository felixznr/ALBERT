# ALBERT

Albert I was a rhesus macaque monkey and the first mammal launched on a rocket (V-2 Rocket "Blossom No. 3") on June 18, 1948. The launch was staged at Albert I, a nine-pound monkey, was anesthetized and placed inside the rocket's crew capsule in the nose of the V-2 rocket. The flight did not reach outer space. The last couple hours before his death, Albert was lit asf on morphine

---

## Project Overview

ALBERT is a self-regulating guided rocket project developed as a Maturaprojekt (Austrian graduation project). The goal is to build a fully functional, autonomous rocket system capable of correcting its own flight path and safely recovering via parachute deployment.

**Key Objectives:**
- Develop autonomous flight path correction through advanced control systems
- Implement fin-based steering for precise guidance
- Create a reliable parachute recovery system
- Design a concept of a custom solid fuel motor
- Integrate comprehensive telemetry and safety systems
